# catsbuy.github.io

Static GitHub Pages site for Cats Buy (catsbuy.com).

[![Visit catsbuy.com](https://img.shields.io/badge/Visit-catsbuy.com-brightgreen)](https://catsbuy.com)  
[![Site status](https://img.shields.io/website-up-down-green-red/https/catsbuy.com)](https://downforeveryoneorjustme.com/catsbuy.com)

What it is
A static website (HTML, CSS, JavaScript) that serves as the public site for Cats Buy. It features a particle-canvas background, a hero with an Explore CTA, and an interactive wheel of project cards. The repository is configured with a CNAME for catsbuy.com.

Files
- `index.html` — main page (hero, canvas, wheel)
- `index.css` — styles, theme variables, animations
- `index.js` — particle background and UI logic (CARDS array / window.addCard)
- `404.html` — friendly not-found page
- `CNAME` — contains `catsbuy.com`
- `favicon.ico` — site icon
